# Типичные имена параметров трекеров в Wialon

Имена сырых параметров зависят от модели трекера и от того, как Wialon разбирает его протокол. Ниже — самые частые варианты. Если параметра нет ни под одним из имён, значит устройство его не передаёт.

## Общие

| Смысл | Частые имена | Как читать |
| --- | --- | --- |
| Внешнее питание (бортсеть) | `pwr_ext`, `power`, `ext_volt`, `extpower`, `vext`, `io_66` | Вольты. Легковая бортсеть ~12–14,5 В, грузовая ~24–28,5 В. Значение больше 1000 — это милливольты, раздели на 1000 |
| Батарея трекера | `pwr_int`, `battery`, `bat_volt`, `vbat`, `io_67` | Вольты, литий-ион: ~3,7–4,2 В норма, ниже ~3,5 В — разряжается. Значения вне 2–5 В — это не батарея трекера, а другой параметр |
| Зажигание | `ignition`, `ign`, `io_239` | 1 — включено, 0 — выключено |
| Движение | `movement`, `moving`, `io_240` | 1 — движется по датчику трекера |
| Уровень GSM | `gsm`, `gsm_level`, `gsmlevel`, `io_21` | Обычно 0–5; 1–2 — слабый сигнал |
| Спутники | `sats` (в позиции сообщения) | Меньше 4 — координаты ненадёжны |

## Teltonika FMB (FMB920, FMB125, FMB130 и др.)

| ID | Параметр | Значения |
| --- | --- | --- |
| `io_239` | Ignition | 0 / 1 |
| `io_240` | Movement | 0 / 1 |
| `io_21` | GSM Signal | 0–5 |
| `io_66` | External Voltage | мВ |
| `io_67` | Battery Voltage | мВ |
| `io_68` | Battery Current | мА |
| `io_69` | GNSS Status | 0 — GNSS выключен, 1 — есть фиксация, 2 — нет фиксации, 3 — GNSS спит |
| `io_200` | Sleep Mode | 0 — не спит, 1 — GPS Sleep, 2 — Deep Sleep, 3 — Online Sleep, 4 — Ultra Sleep |
| `io_181` / `io_182` | GNSS PDOP / HDOP | больше ~3 — точность снижена |

Режим сна объясняет долгие паузы между сообщениями у стоящей машины: в Deep Sleep и Ultra Sleep трекер отключает модем и выходит на связь только по таймеру, заданному в конфигурации. Если последнее сообщение пришло с `io_200` = 2 или 4 при выключенном зажигании, долгое молчание может быть нормой — но если оно длиннее, чем обычный интервал этого объекта, стоит проверить.

## Особенности

- Некоторые модели (часть Queclink, часть китайских трекеров) присылают `pwr_ext = 0` и `battery = 0`, хотя устройство явно работает. Если сообщение свежее, нулевое питание — особенность передачи данных, а не отключение.
- Пользовательские датчики, заведённые в Wialon, могут переименовывать сырые параметры (например, «Бортсеть» вместо `pwr_ext`). Смотри и датчики, и сырые параметры.
