# Где техника: геозоны и группы

Владельцу полезнее «на складе в Сергелях», чем координаты. Для этого используются геозоны, заведённые в Wialon.

## Порядок действий

- **Где весь парк** — `units_by_geofence` без параметров: по строке на машину с её местом.
- **Кто в конкретной зоне** («кто на базе») — `units_by_geofence` с `geofence_name`. Если не уверен в названии зоны, сначала `list_geofences` с `name_filter`.
- **Где одна машина** — `list_units` с `name_filter`, чтобы найти её и время последнего сообщения, затем `units_by_geofence`, чтобы назвать место. Если машина вне зон — покажи последнюю позицию из `list_units`.
- **Какие зоны есть** — `list_geofences`.
- **Группы** («что входит в группу», «сколько машин у филиала») — `list_groups`, с `group_name` для состава конкретной группы. Если пользователь называет группу вместо машины («где техника Самарканда»), сначала узнай состав группы, затем ищи место нужных машин.
- **Молчащие объекты** — по умолчанию `units_by_geofence` учитывает только вышедших на связь за сутки. Если вопрос про весь парк включая молчащих, передай `only_online: false`.

## Как читать результат

- Геозоны вкладываются друг в друга: склад внутри промзоны внутри города. Местом называется самая тесная из накрывающих зон.
- Зоны, помеченные «крупная зона», — это обычно контроль скорости или границы региона. Как адрес они бесполезны; не называй их местом машины, если есть более точная.
- «Вне зон» — точка не попала ни в одну геозону, а не отсутствие координат.
- Место считается по **последней известной позиции**. У молчащих машин оно может быть устаревшим — всегда указывай, когда была эта позиция.

## Как подавать ответ

- Сгруппируй машины по месту: «На базе — 12, на объектах клиентов — 5, в пути — 8, вне зон — 3».
- Таблицу инструмента показывай как есть.
- Если много машин «вне зон» на одних и тех же местах, предложи владельцу завести там геозоны — так ответы станут точнее.
